# ATM

Система банкомата на C# и ASP.NET Core: счета, сессии, пополнение, снятие денег и история операций.

## Возможности

- Пользовательская сессия по номеру счёта и паролю, административная сессия по системному паролю.
- Создание счетов администратором через сервис приложения.
- Просмотр баланса, пополнение и снятие денег по идентификатору пользовательской сессии.
- Проверка положительной суммы операции и достаточного остатка при снятии.
- История успешных пополнений и снятий для каждого счёта.

## Устройство

Гексагональная архитектура с четырьмя проектами:

- `Domain` — счета, сессии и операции.
- `Application` — сценарии банкомата и интерфейсы репозиториев.
- `DataAccess.InMemory` — хранение счетов, паролей, сессий и истории в памяти.
- `Presentation` — HTTP-контроллеры и конфигурация приложения.

Модули регистрируют зависимости через Microsoft.Extensions.DependencyInjection. Бизнес-логика работает с интерфейсами хранилищ. Тесты на xUnit используют подставные реализации репозиториев и проверяют изменение баланса и запись истории.

Данные сохраняются только на время работы процесса. Создание счёта реализовано в `IAtmService.CreateAccount`; отдельного HTTP-метода для него нет.

## Запуск

Нужен .NET SDK 9. Задайте свой пароль администратора через `Admin__Password`:

```bash
Admin__Password='your-admin-password' dotnet run --project src/Presentation --no-launch-profile --urls http://localhost:5135
```

| Метод | Адрес | Назначение |
| --- | --- | --- |
| POST | `/api/createSession/user?accountId=…&password=…` | Пользовательская сессия |
| POST | `/api/createSession/admin?password=…` | Административная сессия |
| GET | `/api/operations/balance/{sessionId}` | Баланс |
| POST | `/api/operations/deposit/{sessionId}?sum=…` | Пополнение |
| POST | `/api/operations/withdraw/{sessionId}?sum=…` | Снятие |
| GET | `/api/operations/history/{sessionId}` | История |
